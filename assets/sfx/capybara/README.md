# Capybara calls

Short excerpts of field recordings, trimmed and loudness-matched for the game.
Each file keeps the license of its source. No clips were taken from YouTube
or other copyrighted video.

## idle.wav

## happy.wav and bump.wav

Two separate calls cut from one recording at ExplorNapo Lodge, Maynas, Peru (observation dated 2008-07-08).

- Source: iNaturalist observation 90187694, sound 288393
- https://www.inaturalist.org/observations/90187694
- Recordist: Stan Rullman
- License: Creative Commons Attribution 4.0 (CC BY 4.0)
- https://creativecommons.org/licenses/by/4.0/
- Attribution: Stan Rullman / iNaturalist (CC BY 4.0).

iNaturalist lists this observation as Greater capybara (Hydrochoerus hydrochaeris).
